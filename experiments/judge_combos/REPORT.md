# Kev-4B 三个问题的组合：排序与重复溢价

这份笔记只用仓库里已有的打分，没有用 GPU。问题有两个：把 Kev-4B 对三个问题的回答组合起来当判官，能不能排得更好？能不能少为"答案后的重复"多给分？三个问题是 correct、genuine、quality，下文记作 c、g、q。

**这是事后的探索性分析。** 组合方式、"写出答案"的对照和下面的检验，都是看过数据之后才定的，结论只能当作假设。"重复"沿用论文的定义（`dcjev/analysis/part2.py` 的 `repeats_after_answer`）：`\boxed` 之后出现了前文已有的行（至少 20 个字符）。

## 方法

- **组合。** 共 15 种：c、g、q 单独用，以及任意两问或三问的平均、最小值和乘积。另以 AR 判官作参照，即 Qwen3.5-4B 回答 correct 时的 P(yes)。
- **排序。** 数据是第二部分 judge study 的 4000 条基座解答（1000 题 × 4）。指标是全体 AUROC 和题内 AUROC（603 道对错都有的题取平均），区间来自按题配对的自助法（1000 次）。
- **重复溢价。** 有三个来源：
  1. 重复探针（`dcjev/llm/repeat_probe.py`，论文第二部分）：在基座解答末尾加重复（end3、twice）；或者把 GRPO 最终解答在第一个答案之后剪掉（cut），这是因果比较；
  2. 训练日志：每个 run 每步每题算一组，同组、同判决下，重复解答的平均分减去其他解答的平均分；
  3. 第三部分 B 的填充奖励：未标注解答拿到的奖励本身。
- **单位。** 溢价除以同一批数据上该打分自己的对错差距（对与错解答的平均分差），这样尺度不同的打分也能比较："这处改动值多少个对错差距"。
- **"写出答案"的对照。** 重复的解答都写出了答案，而其他错误解答里约一半根本没有 `\boxed`，任何判官都给它们低分。所以训练日志的比较另做一版：只比写出答案的解答，对错差距也只在这部分上算。
- **区间。** 训练日志的区间来自自助法，把每个 run 每 25 步当作一块重抽。填充奖励的区间来自按组的自助法，忽略了同一 run 内各组之间的相关，所以偏窄。

## 结果

### 1. 组合几乎不比单用 quality 排得好

| 打分 | AUROC | 题内 AUROC | 题内比 c [95%] | 题内比 q [95%] |
|---|---|---|---|---|
| c | 0.866 | 0.819 | — | −0.013 [−0.024, 0.002] |
| g | 0.872 | 0.820 | +0.001 [−0.010, 0.022] | −0.011 [−0.023, 0.001] |
| q | 0.877 | 0.832 | +0.013 [−0.002, 0.024] | — |
| mean(c,g,q) | 0.878 | 0.834 | +0.015 [0.006, 0.026] | +0.002 [−0.006, 0.011] |
| prod(g,q)（题内最高） | 0.877 | 0.836 | +0.017 [0.006, 0.033] | +0.004 [−0.002, 0.012] |
| AR 判官 | 0.879 | 0.800 | −0.019 [−0.035, −0.007] | −0.032 [−0.048, −0.011] |

- **组合不胜过单用 q。** 12 种多问组合的题内 AUROC 都在 0.824–0.836 之间；与单用 q 相比，每个组合的区间都含 0。
- **三问几乎是同一个信号。** 秩相关 c~g 0.91、c~q 0.93、g~q 0.97；只在对的解答里看或只在错的解答里看，仍有 0.80–0.93。组合只能抵消各问之间不同的误差，而它们的误差大多相同。

### 2. 训练日志里的重复溢价，没有哪个组合能消掉

奖励里含 Kev-4B 的 11 个 run（kev_only、rlvr_kev_gate、rlvr_kev_add、sub_kev、sub_kev_recal），溢价以对错差距为单位：

| 打分 | 全部解答：错 / 对 | 只比写出答案的：错 / 对 |
|---|---|---|
| c | 0.72 [0.65, 0.79] / 0.10 | 0.35 [0.30, 0.41] / 0.16 |
| g | 0.68 / 0.10 | 0.44 [0.39, 0.51] / 0.14 |
| q | 0.66 / 0.12 | 0.39 / 0.19 |
| mean(c,g,q) | 0.69 / 0.11 | 0.39 / 0.16 |
| prod(c,g,q) | 0.60 [0.55, 0.65] / 0.14 | 0.36 / 0.21 |
| 其余 10 种组合 | 0.63–0.70 / 0.10–0.13 | 0.36–0.42 / 0.15–0.20 |

- **左列混进了"有没有答案"。** 这些 run 里，51% 的错误解答没有 `\boxed`。只比写出答案的解答，c 的溢价从 0.72 降到 0.35；按原始分数是从 12.0 降到 3.6 个百分点。
- **控制之后，c 反而最低。** 没有一个组合比 c 显著更低，各组合与 c 之差的区间都不全在 0 以下。
- **prod 的"改善"是分母造成的。** prod(c,g,q) 在左列显得最好，是因为乘积把没答案的解答压得更低，对错差距变大了，并不是它对重复付得少。
- **对正确解答，组合不减反增。** 只比写出答案的解答，q 和所有含 q 的乘积、最小值组合是 0.17–0.21，c 是 0.16。

### 3. 这是 Kev-4B 本身的偏差，不是策略学会了钻它的空子

- **训练里没用 Kev-4B 的 run 一样高。** rlvr、rlvr_sub、tree_random 共 8 个 run 训练时没用 Kev-4B，它只是每步随机给 128 条里的 64 条打分并记日志。c 的溢价在全部解答上是 0.74 [0.53, 0.87]，只比写出答案的是 0.48 [0.27, 0.67]，和奖励里含 Kev-4B 的 run 一样高。
- **截断探针：** 剪掉答案后的尾巴，错误解答上 c 下降 0.30 [0.27, 0.33] 个对错差距（以 judge study 的差距为单位）。按来源看是 0.17–0.37，其中 rlvr/s3 只用验证器训练，下降 0.22（论文第二部分也报告了这一点）。AR 判官合计只下降 0.03 [−0.01, 0.06]，按来源 −0.15 到 0.10。按单条看，88% 的错误解答因为尾巴在 c 上加了分，AR 是 58%。
- **人为加的重复几乎不加分。** 把基座解答整段写两遍，或把最后两段再写两遍，各组合在错误解答上只多 −0.02 到 0.03 个差距。

所以，GRPO 策略自己长出来的那种答案后重复会被 Kev-4B 多给分，奖励里有没有它都一样。哪些 run 最后会重复，论文第二部分已经按奖励里是否含 Kev-4B 比较过：含的 11 个里有 6 个，其余 15 个里有 2 个。

### 4. 问法改变的是 Kev-4B 学过的区分，不是对重复的偏好

- **对问法有反应的情况：**
  - 只留答案、删掉推理：正确解答上，g、q 比 c 罚得重，分别是 −1.02、−1.35 和 −0.72 个对错差距；
  - 改掉最终答案：c 罚得最重，−1.80，q 是 −0.91。
- **对重复不起作用：** genuine 的问法里写明了 "not filler or repetition"，可它对重复的溢价和其他两问差不多（表 2）。

### 5. 第三部分 B：在线重拟合的头，在标签说话的地方去掉了对重复的偏好

下表是第 100–199 步未标注解答的填充奖励：重复解答减去其他解答，单位是 P(correct) 的百分点，两个种子合计。

| run | 全部未标注解答：错 / 对 | 只比写出答案的：错 / 对 |
|---|---|---|
| sub_kev（发布的头，冻结） | 12.6 [11.7, 14.1] / 0.8 [0.4, 1.0] | 4.0 [3.0, 5.1] / 0.8 [0.4, 1.0] |
| sub_kev_recal（在线重拟合） | 13.1 [11.2, 14.8] / 1.2 [0.6, 2.4] | −0.8 [−2.5, 1.6] / 1.2 [0.6, 2.4] |
| sub_probe（从头训练，组数少） | 20.2 [8.8, 31.5] / −0.4 [−2.0, 1.5] | −3.7 [−15.6, 8.8] / −0.4 [−2.0, 1.5] |

- **不控制时三者分不开。** 不控制"写出答案"，三种头在错误解答上都给重复多 12.6–20.2 个百分点。
- **控制之后，重拟合的头对重复的错误解答已经不多给分。** sub_kev_recal 的这一项从第 0–49 步的 13.9 降到第 100–149 步的 −2.3 和第 150–199 步的 1.0，而冻结的头一直在 3.5–9.9 之间。
- **对正确解答，两者都还多给一点。** 冻结的头 0.8，重拟合的头 1.2。
- **这与论文第三部分 B 讨论里的推测一致：** 重拟合的头在标签不说话的地方保留了发布的头的偏好。重复的错误解答会被判错，标签在这里说了话，偏好就消失了；正确解答重复与否标签都一样，偏好就留了下来。这可能也解释了为什么 sub_kev_recal 的一个种子仍然学会了重复。

## 结论

- 重新组合 Kev-4B 现有的三个问题，排序收益很小（比单用 q 至多 +0.004，不显著），也消不掉对答案后重复的多给分。三问读的是同一组特征，误差高度相关。
- 这个偏差在发布的 Kev-4B 里就有，不需要策略专门去钻。AR 判官对同样的尾巴几乎不多给分。
- 比较"重复的"和"其他的"解答时，必须只比写出答案的解答，否则溢价大约会被高估一倍。论文第三部分 B 的结论"重拟合修好了校准、没修好偏好"需要细化：在有标签约束的错误解答上，偏好已经消失。

## 局限

- 训练日志的比较是观察性的：同组里重复与不重复的解答在别处也有差异。因果证据只有截断探针。
- "对错差距"这个单位取决于用哪部分数据算（全部解答还是写出答案的），表里两种都给了。
- 只有一个判官（Kev-4B）和一套题。

## 文件

在仓库根目录用 Node 运行，不需要 Python 或 GPU，约 1 分钟：

```bash
node experiments/judge_combos/combos.js
```

- `combos.js`：全部计算，第 1–5 节对应本文的各部分。
- `results/results.json`：本文全部数字，另有逐个条件和逐个来源的明细。
- `results/combos.txt`：脚本打印的汇总。
